# Integração do menu principal

A análise comparativa foi preparada como componente independente para ser ligada ao menu do aplicativo sem remover as funções existentes.

## Integração pendente no HTML monolítico

O `index.html` deve permanecer com o conteúdo original da `main` enquanto a integração é feita por uma alteração completa e validada do arquivo. Não usar substituição parcial/truncada.

Ponto de entrada: `src/comparison-entrypoint.js`.
